## Description

Application web de gestion d'un cinéma permettant d'administrer les films, les salles et les séances via une interface d'administration complète.

## Fonctionnalités

- CRUD complet sur les films, salles et séances
- Filtrage des films par genre et par année
- Filtrage des séances par date et par salle
- Pagination des listes
- Interface responsive

## Technologies utilisées

- **Front-end:** HTML, CSS, JavaScript (Vanilla)
- **Back-end:** PHP 8.3 (API REST)
- **Base de données:** MySQL

## Défis techniques

Le principal défi était de concevoir une API REST en PHP pur sans framework, en gérant les relations entre films, salles et séances, tout en assurant une interface fluide côté front avec JavaScript Vanilla.
